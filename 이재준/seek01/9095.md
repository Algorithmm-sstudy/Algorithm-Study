## 백준 9095번 1, 2, 3 더하기 (C++)

이번에 풀어본 문제는 **백준 9095번 1, 2, 3 더하기**이다.

문제는 아래 링크에서 확인할 수 있다.  
[https://www.acmicpc.net/problem/9095](https://www.acmicpc.net/problem/9095)

### 💻 코드

```
#include<iostream>
using namespace std;

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);
    cout.tie(0);

    int test, n, arr[12];
    arr[1] = 1, arr[2] = 2, arr[3] = 4;
    cin >> test;
    while (test--) {
        cin >> n; // 양수이며 11보다 작다
        for (int i = 4; i <= n; i++) {
            arr[i] = arr[i-1] + arr[i-2] + arr[i-3];
        }
       cout << arr[n] << "\n";
    }
}
```

### 🔍 로직 설명
n의 범위가 1부터 10이라서 일단 다 적어보았다.
arr[1] = 1 , arr[2] = 2 (1+1, 2), arr[3] = 4 (1+1+1+1, 1+1+2, 1+2+1, 2+1+1, 2+2)
arr[4] = 7, arr[5] = 13이 나왔다. 이렇게 직접 세어보면서 arr[n] = arr[n-1] + arr[n-2] + arr[n-3]
점화식을 찾을 수 있었다.

### ✍️ 느낀 점
숫자들 간의 규칙이 있다고 판단되면 일단 최대한 빨리 적고, 풀고, 수의 관계를 생각하자...
