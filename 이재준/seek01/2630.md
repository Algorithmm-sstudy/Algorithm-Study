## 백준 2630번 색종이 만들기 (C++)

이번에 풀어본 문제는 **백준 2630번 색종이 만들기**이다.

문제는 아래 링크에서 확인할 수 있다.  
[https://www.acmicpc.net/problem/2630](https://www.acmicpc.net/problem/2630)

### 💻 코드

```
#include<iostream>
using namespace std;

int arr[130][130];
int blue, white;

void check(int x, int y, int len) {
    bool cut = false;
    int first = arr[x][y];

    for (int i = x; i < x+len; i++) {
        for (int j = y; j < y+len; j++) {
            if (arr[i][j] != first) {
                cut = true;
                break;
            }
        }
    }

    if (cut) {
        check(x, y, len / 2);
        check(x, y + len / 2, len / 2);
        check(x + len / 2, y, len / 2);
        check(x + len / 2, y + len / 2, len / 2);
    }
    else {
        if (first == 1) {
            blue++;
        }
        else {
            white++;
        }
    }
}


int main() {
    ios_base::sync_with_stdio(0);
    cin.tie(0);
    cout.tie(0);

    int N;
    cin >> N;

    // 하얀색 0, 파란색 1
    for (int i = 0; i < N; i++) {
        for (int j = 0; j < N; j++) {
            cin >> arr[i][j];
        }
    }

    check(0, 0, N);
    cout << white << "\n" << blue;
}
```

### 🔍 로직 설명
분할정복은 divide, conquer, combine 과정을 거친다
N , N / 2를 N이 1이 될 때까지 반복해야하기 때문에 분할정복이라고 생각했다.
그리고 나누는 과정은 재귀를 이용했다.
먼저, 기준을 정한다음 정사각형의 색깔이 모두 같은지 아닌지부터 체크한다.
이후 색깔이 모두 같지 않은 경우 왼쪽 위, 왼쪽 아래, 오른쪽 위, 오른쪽 아래를 재귀를 이용해 나눈다.
같은 경우는 색깔 ++ 해준다.
