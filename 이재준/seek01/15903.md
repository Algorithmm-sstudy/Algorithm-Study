## 백준 15903번 카드 합체 놀이 (C++)

이번에 풀어본 문제는 **백준 15903번 카드 합체 놀이**이다.

문제는 아래 링크에서 확인할 수 있다.  
[https://www.acmicpc.net/problem/15903](https://www.acmicpc.net/problem/15903)

### 💻 코드

```
#include<iostream>
#include<algorithm>
using namespace std;

int main() {
    long n,m;
    cin >> n >> m; // 카드 개수, 합체 몇 번

    long card[n];

    for (int i = 0; i < n; i++) {
        cin >> card[i];
    }

    while (m--) {
        sort(card, card + n);
        long num = card[0] + card[1];
        card[0] = num;
        card[1] = num;
    }

    long sum = 0;
    for (int i = 0; i < n; i++) {
        sum += card[i];
    }

    cout << sum << endl;
}
```

### 🔍 로직 설명
시간 제한을 확인했을 때 1초여서, while문에 sort를 돌리는게 가능할지 의문이었다.
우선순위 큐를 사용해서 두 개 꺼내고, 더한 다음 자동으로 정렬되게 해서 계산하면 될 것이라고 생각했다.
근데 우선순위 큐가 정확히 기억안나서 일단 while문에 sort 넣어서 해봣는데 correct가 떴다.
간단하게 카드 값 결정하고, while문 시작할 때 sort해서 항상 내림차순으로 정렬시켜놓고
[0], [1] 더해서 값 변경하고 m만큼 진행한 뒤 다 더해주면 된다.
